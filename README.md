# Sum and Average of List

## Explanation

This program calculates the total sum and average of numbers entered by the user.

## Problem Statement

Write a Python program to find the sum and average of all elements in a list.

## Features

* Accepts multiple numbers
* Calculates the sum
* Calculates the average
* Displays the results

## How It Works

The `sum()` function calculates the total. The average is calculated by dividing the sum by the number of elements.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `input()`
* `split()`
* `sum()`
* `len()`

## Program Flow

1. Read numbers
2. Convert them into integers
3. Calculate the sum
4. Calculate the average
5. Display results

## Sample Input

```text
10 20 30 40 50
```

## Sample Output

```text
Sum: 150
Average: 30.0
```
